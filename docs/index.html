🧋 Milk Tea Location Scoring Engine

How it works

  1. Data — ~31k points of interest per city pulled from the Overture Maps public S3 bucket with DuckDB (no API keys): existing bubble tea stores, cafés, Asian dining, retail anchors, stations, universities and more.
  2. Geospatial features — aggregated onto an H3 hexagonal grid (~0.74 km² cells) with walkable-catchment counts and CBD distance.
  3. KMeans — clusters every cell into interpretable archetypes (CBD core, high-street strip, neighbourhood centre…).
  4. RandomForest — learns what separates locations that already sustain a bubble tea store from those that don't; every cell is scored out-of-fold, so scores are honest.
  5. Opportunity ranking — suitability discounted by existing nearby supply surfaces underserved whitespace (red stars on the maps).
Any Australian city is a one-line bounding-box change. The production roadmap adds ABS Census demographics, foot-traffic proxies, rents, and an address-level scoring API.
